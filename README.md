# Job Salary & Vacation Prediction (Machine Learning)

Project developed for the **Artificial Intelligence** course at Faculty of Automatic Control and Computer Science, UPB.

## Project Overview
An end-to-end Machine Learning pipeline analyzing job market features to solve two predictive tasks:
1. **Multiclass Classification:** Predict vacation category (`No Vacation`, `Small`, `Medium`, `Large`).
2. **Regression:** Predict continuous employee `salary`.

## Pipeline Stages
* **Exploratory Data Analysis (EDA):** Statistical distributions, missing value checks, outlier detection, and correlation analysis.
* **Data Preprocessing:** Imputation (univariate/multivariate), categorical encoding (One-Hot / Label Encoding), and numeric feature scaling.
* **Model Training & Evaluation:** Decision Trees, Linear/Logistic Regression with regularization, ablation studies, and comparative performance tracking.

## Tech Stack
* **Language:** Python.
* **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn.
