# Job Salary & Vacation Prediction (Machine Learning)

Project developed for the **Artificial Intelligence** course at Faculty of Automatic Control and Computer Science, UPB[cite: 2].

## 📌 Project Overview
An end-to-end Machine Learning pipeline analyzing job market features to solve two predictive tasks[cite: 2, 3]:
1. **Multiclass Classification:** Predict vacation category (`No Vacation`, `Small`, `Medium`, `Large`)[cite: 3].
2. **Regression:** Predict continuous employee `salary`[cite: 3].

## 🛠️ Pipeline Stages
* **Exploratory Data Analysis (EDA):** Statistical distributions, missing value checks, outlier detection, and correlation analysis[cite: 3, 4, 6].
* **Data Preprocessing:** Imputation (univariate/multivariate), categorical encoding (One-Hot / Label Encoding), and numeric feature scaling[cite: 6, 7, 9, 16].
* **Model Training & Evaluation:** Decision Trees, Linear/Logistic Regression with regularization, ablation studies, and comparative performance tracking[cite: 2, 7, 10, 12].

## 🧰 Tech Stack
* **Language:** Python[cite: 13, 14]
* **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn[cite: 5, 14, 16]
